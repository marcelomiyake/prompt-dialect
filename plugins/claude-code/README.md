# prompt-dialect

A Claude Code mod that checks the prompt you are typing. Pause for a moment and a fast model (Claude Haiku 5.5 by default) checks the draft for spelling, grammar, punctuation, and wording. Mistakes are underlined in the prompt box, and a band above the prompt lists them with one-click fixes. Press **✨ Improve** and the draft is rewritten to follow Anthropic's prompting guidance for the model the session uses.

## Install

```
claude plugin install prompt-dialect --marketplace marcelomiyake/prompt-dialect
```

## Use

- Type a prompt and pause. Drafts under three words, `/commands`, and `!shell` lines are skipped.
- Click a chip in the band to apply that fix, or press **Fix all**.
- Press **✨ Improve for …** to rewrite the draft, then **Use it** to put the rewrite in the prompt box or **Copy** to copy it.
- `/dialect off` and `/dialect on` turn checking off and on. `/dialect` alone shows the status.

## Settings

Set them in `/config`: `checkAsYouType` (default `true`), `grammarModel` and `improvementModel` (default `claude-haiku-5-5`), and `debounceMs`, the pause before a check (default `900`, from 250 to 10000).

## What it reads, sends, and stores

- **Reads** the text in the prompt box and the name of the session's model.
- **Sends** the prompt box text, with the mod's instructions, to the configured Claude model through Claude Code's own API client: one call each time you pause typing, and one each time you press Improve. The calls count toward your usage like any other request. The mod makes no other network requests and reads no environment variables or credentials.
- **Stores** only your `/dialect on|off` choice, in Claude Code's plugin store. The current draft's suggestions are kept in the session's plugin state so they survive a reload, and drafts already checked are cached in memory.
- **Writes** to the prompt box only when you apply a fix or press **Use it**, and to the clipboard only when you press **Copy**.
- **Hooks** `session.start` to register `/dialect`; `command.run` for `/dialect` only, so every other command passes by untouched; `prompt.edit` and `prompt.change` to follow the draft as it changes; and `ui.render` for the band above the prompt.

## Source

`hooks/register.js` is generated by esbuild from the TypeScript in [`src/`](https://github.com/marcelomiyake/prompt-dialect/tree/main/src) and is not minified. The [project README](https://github.com/marcelomiyake/prompt-dialect#readme) covers the design and development.
